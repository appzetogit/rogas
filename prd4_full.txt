15. Language Management — How It Works 
 
No developer needed to add a new language. Admin uploads a JSON translation file → system validates → OTA push to all apps in that city. Apps fetch on 
open + every 2 hours. New language live within 15 minutes of admin approval. 
15.1 Adding a New Language — Step by Step 
Step 
Action 
Detail 
1 
Prepare translation file 
Translator creates de.json (German) following the English master format. Every key from en.json must be present. 
2 
Upload in Admin Panel 
Admin Panel → AP-13 → Languages → Upload → select de.json → select city: Berlin. 
3 
System validates 
Backend checks: all keys present vs English master, no empty values, correct JSON format. Shows missing keys if any. 
4 
Admin approves 
If validation passes: Admin clicks "Approve & Push". Firebase Remote Config updated with translation URL. 
5 
OTA push to apps 
All apps in Berlin fetch new config on next open (or within 2h background refresh). Translation applied immediately — no 
reinstall needed. 
6 
User sees language 
Customer, vendor, and driver apps in Berlin now show German text. User can still override in their Profile settings.
